## Installation via Homebrew

Run the following command in your macOS Terminal:

```bash
brew tap fsakbas/tap
brew install --cask iphone-data-manager
```

Or install in a single command:

```bash
brew install --cask fsakbas/tap/iphone-data-manager
```

### Updating

```bash
brew upgrade --cask iphone-data-manager
```

## Key Features

- **Local & External SSD Backups**: Create full local iPhone backups to your Mac or external drives with real disk write progress, or use **Lean Mode** to back up only core databases (WhatsApp, Contacts, SMS) when disk space is tight. Supports both unencrypted and password-encrypted backups.
- **Data Time Machine & Backup Health Check**: Compare any two backups across different dates to inspect added, modified, or deleted records, and run SHA-1 manifest integrity audits.
- **WhatsApp Chat Reader, Lead Extractor & SHA-256 PDF Transcripts**: Smoothly browse tens of thousands of WhatsApp messages offline. Export chats to CSV, extract structured business leads (phone numbers, emails, physical addresses, and valid IBANs), and generate tamper-evident printable PDF transcripts with SHA-256 message and document root hashes.
- **Photos, Messages & Contacts**: Preview camera roll items with exact byte sizes before parallel export, export SMS/iMessage threads, and export clean vCard 3.0 (`.vcf`) contact files.
- **Pro iOS Diagnostics**: Inspect true battery cycle counts, design vs. current capacity, installed app inventories, crash reports, and live iOS system logs.

## System Requirements

- **macOS 12 Monterey** or later
- **Apple Silicon** Mac (M1, M2, M3, M4 or later)
- Notarized by Apple · Strictly read-only device access · Zero cloud telemetry
